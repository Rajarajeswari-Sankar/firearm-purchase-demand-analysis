# Firearm Purchase Demand Analysis

## Overview
This project analyses firearm background check trends in the United States using FBI NICS data (1998–2024).

The project explores:
- State-level firearm demand
- Growth and trend analysis
- Seasonal patterns
- Permit vs purchase composition
- Forecasting future demand

## My Contribution
I developed the “State-Level Firearm Demand: Growth, Trend and Composition” analysis.

My work included:
- Calculating month-over-month demand growth
- Regression slope trend analysis
- State-level demand comparison
- Interactive dashboard development
- Interpreting demand shifts across states

## Key Insights
- COVID-19 created major demand spikes in 2020
- Handgun demand dominated most states
- Illinois showed high permit-related administrative checks
- Growth and slope analysis revealed temporary vs sustained demand increases
